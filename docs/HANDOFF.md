# Перенос popovichfit.ru с Тильды — передача

Дата: 18.09.2026 (первая версия 17.09). Исходник — экспорт Тильды (архив `natalya-popovich_….zip`, распакован в `old-site/`, в git не входит).
Стек: Nuxt 4 + Vue 3 + Tailwind 4 + TypeScript. Структура и команды — в `README.md`.

## Что перенесено

- Все 220 страниц экспорта (219 + стандартная 404) с теми же адресами; 47 страниц без slug доступны как `/pageNNN.html`.
- 1651 Zero Block отрисовываются из данных экспорта (артборды 1200/960/640/480/320 и 1600 там, где он есть, группы, flex, иконки,
  пошаговые анимации при наведении, попапы), типовые блоки (FAQ T585, табы T395, видео, галереи T746/T604/T670, попапы
  T390/T702/T868/T1093) — из HTML экспорта и его CSS (без runtime Тильды: слайдеры, аккордеоны, табы, попапы — свой код);
  главная — тем же рендерером.
- Анимации: появление элементов при прокрутке (данные t-animate Тильды → `app/utils/appear.ts`, CSS в `tilda-blocks.css`), hover-переходы,
  раскрытие FAQ, перелистывание слайдеров, вкладки, «показать ещё», попапы/корзина/меню — плавные, как на Тильде; в Playwright
  (navigator.webdriver) и при prefers-reduced-motion анимации появления отключены (скрипт в `<head>`, nuxt.config).
- Шапка, мобильное меню, футер, cookie-баннер, плашка ВК, виджет поддержки Sender — общие компоненты.
- Реферальная программа `?r=` + utm: параметры дописываются во все ссылки сайта и на `lk.popovichfit.ru/…/checkout`
  (замена ~15 скриптов), ссылка на бот предзаписи при `r` подменяется на salebot — как было.
- Карточки тарифов (варианты потоков → цена и ссылка на checkout ЛК) — `app/data/tariffs.ts`.
- Виджет тарифов (`/korrekciya-new`, `/silovye-new`; в Тильде — iframe с GitHub Pages `elenasamanchuk.github.io/popovichfit-tariffs`)
  реализован в коде сайта без iframe: `app/components/site/TariffsWidget.vue` + сгенерированные `app/utils/tariffs-widget.js`,
  `app/assets/css/tariffs-widget.css`, `public/tariffs/assets/*` (скрипт `scripts/build-tariffs-widget.mjs` из репозитория
  `popovichfit-tariffs`). Тексты и цены — `config-korrekciya.json` / `config-silovye.json` из ветки `main` того же репозитория:
  `/api/tariffs/<course>` берёт их с GitHub (кэш 10 минут, при недоступности — копия из сборки `app/data/tariffs-widget/`),
  так что админка виджета, коммитящая конфиг в GitHub, продолжает работать. Попап подписки, автоскейл на телефонах (<480 px,
  как у Zero Block), ссылки на checkout ЛК — те же, что в виджете.
- Формы: Zero Block и попапы T702 → `POST /api/lead`; корзина T706 (`#order:Товар=цена`, /gift1, /mk_msk и др.) → `POST /api/order`
  → виджет CloudPayments → вебхук `POST /api/cloudpayments/pay`. Заявки/заказы дублируются в `.data/*.jsonl`.
- Метрика 88400923 и VK-пиксель — свои подключения (`app/plugins/analytics.client.ts`); ни одного обращения к Тильде
  (проверка `npm run check:no-tilda`).
- Картинки экспорта — WebP (оригиналы > 2400px уменьшены), og-картинки — `public/img/og`, шрифты Involve/Manrope/Unbounded — свои файлы.
- SEO: title/description/og/canonical/noindex — дословно из экспорта (проверка `scripts/check-seo.mjs`: 219/219 совпадают),
  `sitemap.xml` (179 индексируемых страниц), `robots.txt`, 301 с `/pageNNN.html` на slug, нижний регистр, без завершающего слэша.

## Что нужно от заказчика

1. **CloudPayments**: Public ID и API-секрет → `NUXT_PUBLIC_CLOUDPAYMENTS_PUBLIC_ID`, `NUXT_CLOUDPAYMENTS_API_SECRET`;
   в кабинете CloudPayments указать URL уведомления «Pay»: `https://popovichfit.ru/api/cloudpayments/pay`.
   Без Public ID корзина принимает заказ и показывает «заказ принят», оплата не запускается.
2. **Уведомления о заявках**: Telegram-бот и chat_id (`NUXT_TELEGRAM_*`) и/или SMTP (`NUXT_SMTP_URL`, `NUXT_MAIL_TO`).
3. **DNS** (reg.ru): после проверки сайта по IP — A-записи `@` и `www` → 146.185.241.179, затем `certbot --nginx` и `server_name` в nginx.
4. Проверить тексты писем/полей форм, если хочется что-то поменять (сейчас — дословно как в Тильде).
5. **Перед переносом домена — свежий экспорт Тильды** (заказчик продолжает править сайт: 18.09 на главной изменили счётчик участников);
   после экспорта: распаковать в `old-site/`, `python3 scripts/audit/build_tilda_json.py`, выкладка. Промежуточные правки — `scripts/check-live-texts.mjs`.
6. Список страниц, скрытых в Тильде (неопубликованных), если их нужно перенести: их нет в экспорте — понадобится их HTML/экспорт
   отдельно; механизм скрытия уже есть (`docs/unpublished.json`).
