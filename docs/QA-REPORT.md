# QA-отчёт: popovichfit.ru без Тильды

Дата: 18.09.2026 (первая версия 17.09). Сравнение с живым сайтом https://popovichfit.ru (пока он на Тильде). Инструменты — в `README.md`.

## 1. Структура и адреса

- 219 страниц экспорта + 404: все адреса отвечают 200 (`scripts/check-urls.mjs`: ✓ 219/219), `/pageNNN.html` для страниц со slug → 301 на slug,
  `/About` → `/about`, `/about/` → `/about`, несуществующие → своя 404 (в общей обёртке сайта).
- Порядок и набор блоков на каждой странице — как в экспорте (данные `app/data/tilda/*.json`); общие блоки (шапка, меню, футер, cookie,
  плашка ВК) заменены компонентами; попапы открываются по тем же hash-ссылкам (`#popup:…`, `#zeropopup`, `#tarif1`…).
- Внутренние ссылки: 10 975 проверены, битых 0; 8 адресов ведут на страницы, которых нет и на Тильде (403 — не опубликованы) —
  список в `scripts/known-dead-links.json`, `/members/*` → редирект в ЛК.
- Ни одного обращения к tilda.cc / tildacdn.com / tilda.ws (`scripts/check-no-tilda.mjs` по исходникам и сборке).

## 2. Копирайтинг (тексты)

- Тексты элементов Zero Block сверяются дословно с живыми замерами (`measure-diff`, нормализация пробелов/nbsp) — см. §5.
- Типовые блоки (FAQ, таблицы, попапы) переносятся HTML-разметкой экспорта без изменений.
- SEO-тексты: title / description / og:title / og:description / canonical / noindex — совпадают на 219/219 страницах (`scripts/check-seo.mjs`).

## 3. Креативы (картинки, видео, иконки)

- 149 og-картинок, все картинки экспорта (WebP, оригиналы > 2400px уменьшены), SVG-иконки кнопок — свои файлы; 404 по картинкам: 0
  (`check-console` по 219 страницам; единственные внешние 404 — приватные видео Google Drive на /menu, /page01…/page03, /7day…/9day —
  так же и на Тильде).
- Видео Kinescope / YouTube / VK — те же iframe (ленивая загрузка), фиксированные фоны T674 — свои картинки.
- Фон фигур: картинка + градиент (как на Тильде), превью `-/resize/20x/` заменены оригиналами.

## 5. Вёрстка и адаптив

Сверка геометрии, шрифтов, цветов, фонов и текстов каждого элемента Zero Block с живыми замерами
(`docs/specs/diff/SUMMARY.md` — 1200 px, `SUMMARY-320/480/640/960.md` — мобильные ширины; порог 3 px, 205 страниц на каждой ширине;
итоги последнего прогона — в самих файлах):

- На 1200 px: **170** страниц без расхождений или с ≤ 2 (косметика), **201** — с ≤ 5; главная — 0 расхождений; высоты страниц совпадают
  с живым сайтом (кроме случаев ниже).
- Ожидаемые/намеренные отличия: `/gift1` без демо-квиза (−1046 px); страницы уроков и часть страниц выше на 54 px — без мусорного текста
  Collabza (три пустых T123 с «Collabza error… подписка истекла»); `/members/*` — редирект в ЛК; скрытые вкладки T395/T1281 и блоки
  «показать ещё» локально не в DOM; типографика по просьбе заказчика — неразрывный пробел после коротких предлогов/союзов и без точки
  в конце абзаца (тексты сверяются без учёта пунктуации).
- Экраны ≥ 1600 px: у 6 блоков (первые экраны страниц курсов: `/course_correction`, `/course_power`, `/page51632977.html`,
  `/page70505671.html`, `/page70866373.html`) в Тильде есть отдельный артборд «1600» — перенесён (на 1710 px геометрия совпадает
  с живым сайтом: баннер во всю ширину, высота 690); у остальных блоков сетка 1200 и на широких экранах.
- Остаточные расхождения на страницах с наибольшим счётом (`/course_power`, `/page70866373.html`, `/page70505671.html`, `/page70281657.html`,
  `/regime`, `/max`): фон полупрозрачных «кружков» при наведении (0.1 opacity белый vs прозрачный — визуально неотличимо) и
  интерлиньяж текста кнопок (`normal` vs 1.55 при однострочном тексте — не влияет на вид); реальных смещений > 3 px не осталось.
- Скриншоты 1200/390 против живого сайта (`docs/MIGRATION-STATUS.md`): `/` 3.3 % / 8.7 %, `/course_correction` 0.8 % / 7.6 %,
  `/about` 2.9 % / 7.2 %, `/new-course` 0.7 % / 7.9 %, `/media` 0.5 % / 9.2 % (мобильные 7–9 % — сглаживание шрифтов и масштаб фото).

Правки 18.09 (после выкладки 09:31): синий баннер «Чтобы ничего не потерялось…» на главной — в экспорте у группы текстов потеряна
обёртка tn-group (молекула без группы), тексты уезжали к левому краю; парсер строит группу из CSS, а координаты группы
(CSS экспорта устарел) — из замера живого сайта на всех ширинах (`scripts/audit/fixups.json`). Попапы и корзина закрываются
кликом по фону вне окна (раньше клик перехватывала внутренняя обёртка). Рамка у иконки ВК: у Тильды
`border-color: var(--t396-bordercolor, transparent)` без переменной = прозрачная, а preflight Tailwind давал чёрную — прозрачность
пишется явно.

Исправлены системные ошибки экспорта/рендера:
несбалансированный HTML атомов, устаревшие координаты групп, пустые `width:px`, центрированные элементы, `@supports`-фолбэки,
шрифты Manrope/Arial/RockStar, списки, табы из блоков, absolute-артборды, видимость по ширине экрана, проценты от сетки (а не окна)
на широких экранах, blur у полупрозрачных элементов, состояние покоя sbs-анимаций, артборд 1600, галереи T746.

Замечания ревьюера от 17.09 (по сборке 16:05) и их статус: выравнивание текста в меню, тени карточек, вес шрифта кнопок, плашка ВК
и стрелка в её кнопке, «матовые» кнопки, текст ТЕХ.ПОДДЕРЖКА по центру, FAQ (серый мелкий текст, автозакрытие), расстояния в футере,
ширина баннера на широких экранах, blur плашек/подложек табов, галереи сертификатов/отзывов, подложка модальных окон, скругления
иконок, мобильная главная, белый фон медиа-страниц, прозрачность баннера прогресса, кнопка «всегда белая», иконка «?» и хештег
на главной, висячие предлоги/точки — исправлены и сверены с живым сайтом (замеры и скриншоты). Не воспроизвелись по описанию:
«стрелки лишние» (стрелки горизонтального скролла на `/course_correction` есть и на живом сайте на 1200/1600/1710 px — уточнить у ревьюера,
где именно) и «иконка вопроса не кликабельна» (на живом сайте она тоже без ссылки).

Мобильная версия: артборд 320 масштабируется на ширину экрана (как у Тильды, шрифты не масштабируются),
480 — при `upscale=window`; проверка на 320 — выборочно (см. ниже).

тестовых страниц (`/payment-test`, `/page58618145.html` — на живом сайте они опустошены), остальные 217 идентичны. Карта сайта Тильды
(176 URL) полностью покрыта; сверх неё перенесены 43 скрытые/noindex страницы экспорта.

## 8. Фреймворк и паттерны

Nuxt 4 (файловый роутинг, `useAsyncData`, SSR + пререндер), Vue 3 `<script setup>` + TS, Tailwind 4 (`@theme`-токены), данные экспорта
как серверные ассеты (не бандлятся), серверные роуты Nitro для форм/корзины/вебхука, плагины для сквозного поведения (ref-params,
modal-links, tilda-forms), генерация CSS Zero Block из JSON (`app/utils/tilda-css.ts`). Консоль: ошибок гидрации нет на всех 219 страницах.
