# QA-отчёт: popovichfit.ru без Тильды

Дата: 17.09.2026. Сравнение с живым сайтом https://popovichfit.ru (пока он на Тильде). Инструменты — в `README.md`.

## 1. Структура и адреса

- 219 страниц экспорта + 404: все адреса отвечают 200 (`scripts/check-urls.mjs`: ✓ 219/219), `/pageNNN.html` для страниц со slug → 301 на slug,
  `/About` → `/about`, `/about/` → `/about`, несуществующие → своя 404 (в общей обёртке сайта).
- Порядок и набор блоков на каждой странице — как в экспорте (данные `app/data/tilda/*.json`); общие блоки (шапка, меню, футер, cookie,
  плашка ВК) заменены компонентами; попапы открываются по тем же hash-ссылкам (`#popup:…`, `#zeropopup`, `#tarif1`…).
- Внутренние ссылки: 10 975 проверены, битых 0; 8 адресов ведут на страницы, которых нет и на Тильде (403 — не опубликованы) —
  список в `scripts/known-dead-links.json`, `/members/*` → редирект в ЛК.
- Ни одного обращения к tilda.cc / tildacdn.com / tilda.ws (`scripts/check-no-tilda.mjs` по исходникам и сборке).

## 2. Копирайтинг (тексты)

- Тексты элементов Zero Block сверяются дословно с живыми замерами (`measure-diff`, нормализация пробелов/nbsp) — см. §5.
- Типовые блоки (FAQ, таблицы, попапы) переносятся HTML-разметкой экспорта без изменений.
- SEO-тексты: title / description / og:title / og:description / canonical / noindex — совпадают на 219/219 страницах (`scripts/check-seo.mjs`).

## 3. Креативы (картинки, видео, иконки)

- 149 og-картинок, все картинки экспорта (WebP, оригиналы > 2400px уменьшены), SVG-иконки кнопок — свои файлы; 404 по картинкам: 0
  (`check-console` по 219 страницам; единственные внешние 404 — приватные видео Google Drive на /menu, /page01…/page03, /7day…/9day —
  так же и на Тильде).
- Видео Kinescope / YouTube / VK — те же iframe (ленивая загрузка), фиксированные фоны T674 — свои картинки.
- Фон фигур: картинка + градиент (как на Тильде), превью `-/resize/20x/` заменены оригиналами.

## 5. Вёрстка и адаптив

Сверка геометрии, шрифтов, цветов, фонов и текстов каждого элемента Zero Block с живыми замерами
(`docs/specs/diff/SUMMARY.md`, порог 3 px): см. итоговые цифры ниже. Исправлены системные ошибки экспорта/рендера:
несбалансированный HTML атомов, устаревшие координаты групп, пустые `width:px`, центрированные элементы, `@supports`-фолбэки,
шрифты Manrope/Arial/RockStar, списки, табы из блоков, absolute-артборды, видимость по ширине экрана.

Мобильная версия: артборд 320 масштабируется на ширину экрана (как у Тильды, шрифты не масштабируются),
480 — при `upscale=window`; проверка на 320 — выборочно (см. ниже).

## 6. Кроссбраузерность

Скриншоты в WebKit (Safari) и Firefox против Chromium, 1200 px (`scripts/check-browsers.mjs`):
`/` 1.1 % / 1.9 %, `/course_correction` 0.7 % / 1.0 %, `/gift1` 0.7 % / 0.8 %, `/about` 0.4 % / 0.5 % отличий, высоты совпадают, ошибок консоли нет.

## 7. SEO

- Мета 219/219 как на Тильде; `lang="ru"`, viewport, favicon, yandex-verification; canonical без слэша; `robots.txt`; `sitemap.xml` (179 индексируемых).
- Заголовки h1/h2/h3 из Zero Block сохраняют теги (59 элементов: 12 h1, 25 h2, 22 h3); на 207 страницах h1 нет — как и на Тильде (рекомендация на будущее).
- Все страницы — статический HTML (пререндер), без JS-зависимости для контента; картинки WebP с lazy-loading.

## 8. Фреймворк и паттерны

Nuxt 4 (файловый роутинг, `useAsyncData`, SSR + пререндер), Vue 3 `<script setup>` + TS, Tailwind 4 (`@theme`-токены), данные экспорта
как серверные ассеты (не бандлятся), серверные роуты Nitro для форм/корзины/вебхука, плагины для сквозного поведения (ref-params,
modal-links, tilda-forms), генерация CSS Zero Block из JSON (`app/utils/tilda-css.ts`). Консоль: ошибок гидрации нет на всех 219 страницах.
